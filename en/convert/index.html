Get your drawings ready for the phone

Turns SketchUp, OBJ and AutoCAD files into something LampOff Mobile can open: 3D models become a light, coloured GLB; DWG drawings become DXF. Conversion runs in this browser and your file is never uploaded.

Opening it in LampOff

  1. Send the converted file to your phone (email, WhatsApp or Google Drive).
  2. Choose it with LampOff › File › Import from another program.
  3. GLB (SketchUp, OBJ): tap Add as 3D scenery. The model shows from above on the plot and in full in 3D; you can move, rotate and resize it.
    DXF (AutoCAD): pick the layers, then Place on plot. The drawing becomes an underlay on the plot.

Good to know

  • Use a computer for large files. A 100 MB SketchUp or 300 MB OBJ file needs 1–2 GB of memory and about half a minute to open. Only small files can be converted on a phone.
  • Colours come through, textures don’t. Each SketchUp material keeps its colour. For OBJ, choose the .mtl file together with the OBJ; otherwise colours are guessed from material names.
  • Check the unit for OBJ. The model size is shown after conversion; if it is wrong, pick the unit and convert again.
  • Stray far-away parts are dropped. Pieces lying far from the model (for example an object left kilometres away) are left out.
  • Hidden layers are skipped (SketchUp). Hide what you don’t need (trees, people, the ceiling) and save; the model comes out lighter and cleaner.
  • For DWG, 2D plan drawings work best. Files from AutoCAD R14 to 2018 and later are read. Lines, arcs, blocks, dimensions and text come through; hatches, tables and 3D solids do not.
  • If a file can’t be read, write to lampoff.info@gmail.com.

SketchUp files are read with the open-source OpenSKP, DWG files with GNU LibreDWG (licences and source code). SketchUp is a trademark of Trimble Inc.; AutoCAD and DWG are trademarks of Autodesk, Inc. LampOff is not affiliated with these companies.
