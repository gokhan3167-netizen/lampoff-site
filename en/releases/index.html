Releases

What was added and improved in each version. Updates arrive through Google Play and the App Store.

7.12.8

19 November 2026Latest

New light engine: real shadows and volumetric beams. Import chosen parts from another project, Save / Save as.

What’s new

  • New light engine: real shadows and volumetric beams; it lightens itself on slower devices.
  • New logo.
  • Import from another project: add or update the parts you choose (patch, focus, color, trusses, decor…).
  • Save writes over the same file, Save as asks for a new name; 3D model decor is saved in the project file.
  • Duplicate trusses, multi-truss settings, fixtures on the floor, layer lock.
  • Rider: current per truss and number of 16 A circuits.

Improvements and fixes

  • The My files list fills again; saved files weren’t showing.
  • Light no longer passes through curtains and decor; at full zoom the beam lands exactly on the floor.
  • The halo around shuttered spots and the pattern on the floor are gone.
  • LED PAR light no longer looks spotty, so focusing is easier.
  • On phones: the error when switching from Persp to 3D is fixed; hint texts no longer squeeze, and Fit no longer hides the plot under the buttons.
  • Plot (PDF) now gives just the plot; the help freezing in French and untranslated headings are fixed.

7.12.7

14 November 2026

Shutters for profiles, 3D scenery models and refreshed PDF output.

What’s new

  • Shutters added for profiles: blades rotate one by one or together, with a hard or soft edge.
  • OBJ, GLB, glTF and STL models can be imported as 3D scenery, coloured on the plot and complete in 3D.
  • Plot PDF added with a preview window; Ch numbers on the plot are optional in the rider and plot PDFs.
  • Standard and Vector modes added for the Clay Paky Alpha 1500 family.

Improvements and fixes

  • Over-bright profiles and reflections on iPhone were fixed.
  • Copying multi-selected scenery, objects and text together was fixed.
  • Plot symbols now show their body in colour as well.
  • PDF import was improved: double-line truss, adjacent symbols and stage size are read correctly.
  • Stutter when switching the floor between matte and glossy was fixed.

7.12.6

12 November 2026

Intro cards added; LampOff is now on iPhone and iPad.

What’s new

  • A short intro card was added to every section on first visit; reopen it with ?, and jump to the matching guide chapter.
  • LampOff was released for iPhone and iPad on the App Store.

7.12.5

10 November 2026

File menu, separate Select and Move tools, smoother plot.

What’s new

  • New File menu: new, open, save, My projects, project info, export and import in one place.
  • Select and Move were separated: nothing moves in Select. Multi-select was added to the toolbar.
  • Ch bubbles were added above fixtures in 3D Focus mode; tap one to select it.
  • Seated performer and new 3D objects were added.
  • The user guide was rewritten in Turkish and English.

Improvements and fixes

  • One-finger panning on empty space was improved.
  • Stutter while panning and dragging in large projects was fixed.
  • Fixture modes are now named by ch count (4 ch, 8 ch…).
  • Stage size not being found when importing borderless PDF plots was fixed.

7.12.4

9 November 2026

.loff project file, DXF underlay and angled truss.

What’s new

  • LampOff’s own .loff project file was added; tap one on the phone to open it in LampOff. Older .json files still open.
  • Venue drawings can be added as a DXF underlay: layer selection, crop, units and scale.
  • Circle truss can stand upright or tilted; straight truss can be angled.
  • Gobo patterns are now visible in the air in 3D.

Improvements and fixes

  • Saving no longer overwrites a file with the same name.
  • Truss drawing in the perspective plot was improved to match the profile.
  • 3D figures were improved.
  • Beams hitting a small obstacle now reach the floor.
  • A line-like glare on floor-standing fixtures was fixed.

7.12.3

9 November 2026

Truss library, 3D that matches the plot, and new rider pages.

What’s new

  • Truss library added: 2-, 3- and 4-chord profiles at true width, circle truss, ground support and corner blocks.
  • Truss can be set to any angle; crossing trusses pass over each other.
  • Drapes, scenery and audience areas from the plot now appear in the same place in 3D. New template: TV / film studio.
  • Fixtures accept colour codes such as L201, R80 or #FF8800.
  • Rider now has separate conventional and moving Ch lists, plus focus records.

Improvements and fixes

  • 3D performance was improved; stutter while orbiting and the “not responding” warning were fixed.
  • The 3D floor is now matte by default.
  • Patch is kept when the model or type changes; undo / redo was added to the patch list.
  • Conventional fixture symbols now point to their focus point.
  • Plot PDFs are much smaller.

7.12.2

7 November 2026

DMX map; fixture number is now the console Ch.

What’s new

  • DMX map added: all 512 ch of each universe in colour (used, free, conflicting); unaddressed fixtures can be patched from the map.
  • Fixture number and console Ch were merged.
  • The app tells you on launch when a new version is out.

Improvements and fixes

  • Save and Open were simplified.
  • Pinch-zoom in split view was fixed.
  • Closing a menu by tapping outside no longer clears the selection.
