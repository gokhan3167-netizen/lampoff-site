light2light · 近日公開

ショーを、ある卓から別の卓へ。

light2light は、ある照明卓でプログラムしたショーファイルを、別の卓で開けるショーに変換します。Patch、キュー、プリセットを手で作り直す必要はありません。卓が変わっても、ショーはそのままです。

変換の組み合わせ

検証済み

Strand NEO → grandMA2

検証済み

Strand NEO → grandMA3

開発中

grandMA2 → ETC Eos

ほかの卓（grandMA3 → ETC Eos、Avolites、Hog、ChamSys MagicQ…）も順次追加します。

引き継がれる内容

Patch と Fixture タイプ

アドレスと Universe はそのまま。変換先の卓のライブラリにない Fixture は、元のショーの定義から作成されます。

キューとタイム

キュー番号、名前、フェード・ディレイ・フォローのタイム。トラッキングも保たれます。

パレット → プリセット

Intensity・Position・Color・Beam のパレットはプリセットになり、キューとのリンクも保たれます。

グループとレイアウト

グループは選択順を保ちます。Fixture のモデルごとにグループとレイアウトを用意します。

エフェクト

エフェクトは速度・サイズ・フェーズごと引き継がれ、終わるキューで止まります。

すぐ使える画面

変換先の卓ではシーケンス、レイアウト、プリセットのウィンドウが開いた状態で、すぐに作業を始められます。

使い方

  1. ショーファイルを選ぶ。元の卓のショーのバックアップをプログラムにドロップします。
  2. 変換する。light2light が Fixture を照合し、キューとプリセットを変換先の卓の形式で書き出します。
  3. 変換先の卓で開く。空のショーでコマンドひとつで読み込めます。卓用の USB フォルダーも用意されます。

変換は毎回チェック

変換後、元のショーの全キューの DMX 値を新しいショーと一つずつ照合し、レポートを書き出します。実際の演劇公演で検証済みです。
